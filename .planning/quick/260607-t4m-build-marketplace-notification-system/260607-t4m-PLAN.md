# Quick Task 260607-t4m: Build Marketplace Notification System

Date: 2026-06-07
Mode: quick-full

## Objective

Add a complete, real-feature marketplace notification system for buyer, seller, and admin users using Laravel notifications, database notifications, mail for important events, role-safe UI, translations, tests, seed data, docs, and changelog updates.

## Scope

- Implement only real supported flows: orders, order status changes, product active/moderation decisions, moderation-required alerts, and stock thresholds.
- Do not invent message, dispute, refund, report, or full review workflows.
- Use the built-in Laravel `notifications` table instead of the pending custom `user_notifications` table.
- No broadcast/realtime channel in this iteration.

## Tasks

1. Notification Foundation
   - Add standard Laravel database notification migration.
   - Create marketplace notification classes and shared payload helpers.
   - Ensure important notifications are queueable and dispatch after successful persistence.

2. Domain Triggers
   - Send order-created and new-order notifications from checkout.
   - Convert existing order-status notification to database + mail with correct related URLs.
   - Send product moderation-required, approved, rejected, low-stock, and out-of-stock notifications from product flows.
   - Prevent duplicate low-stock spam.

3. Notification UI
   - Add guard-specific notification list components and routes.
   - Add header/backend notification dropdowns with unread counts.
   - Add dashboard recent notifications for buyer, seller, and admin.
   - Implement mark single and mark all as read.

4. Translations, Seeders, Docs
   - Add all notification keys to `lang/en.json` and `lang/lt.json`.
   - Seed demo buyer/seller/admin notifications.
   - Document architecture and setup in `docs/notifications.md`, README, and changelog.

5. Tests And Verification
   - Add PHPUnit feature tests for dispatch, payload, URLs, read actions, authorization, translation coverage, queueability, and duplicate stock prevention.
   - Run focused tests, Pint, fresh migrations/seeders, full suite as feasible, and frontend build.

## Verification Commands

- `php artisan test --compact tests/Feature/Notifications`

- `vendor/bin/pint --dirty --format agent`

- `php artisan test --compact`
