# Release 0.3.0 - Product Stock Alerts

## Metadata

- Version: `0.3.0`
- Release date: 2026-06-07
- Release type: minor pre-release feature
- Related commits: `feat: add back in stock notifications`
- Related issues: none documented
- Git tag: not created by this implementation

## Summary

This release adds buyer product stock alerts and back-in-stock database notifications for visible marketplace products.

## Main Changes

- Authenticated buyers can subscribe to out-of-stock visible products.
- Buyers can view active, notified, and cancelled alerts from their buyer area.
- Product updates automatically notify active subscribers when a product becomes purchasable again.
- Alert creation, cancellation, and notification delivery are audit logged.

## Added

- `product_stock_alerts` table with buyer/product/status uniqueness.
- Stock alert model, factory, enum, policy, actions, observer, notification, Livewire page, and buyer dashboard panel.
- Product detail subscribe/cancel controls for out-of-stock products.
- Demo stock-alert seed data.
- English and Lithuanian stock-alert translation keys.
- Stock alert documentation and PHPUnit coverage.

## Changed

- Product availability helpers now centralize visible/purchasable stock-alert rules on `Product`.
- Marketplace notifications documentation now includes back-in-stock buyer alerts.

## Fixed

- None.

## Removed

- None.

## Security

- Guests cannot subscribe to stock alerts.
- Sellers cannot access buyer stock alert lists.
- Buyers can cancel only their own alerts.
- Back-in-stock notifications are not sent for inactive, deleted, hidden, or seller-unavailable products.

## Deprecated

- None.

## Database Changes

- Added `product_stock_alerts` with `product_id`, `buyer_id`, `status`, `notified_at`, timestamps, supporting indexes, and a unique product/buyer/status constraint.

## Configuration Changes

- No new `.env` keys.
- No config file changes.

## New Routes Or Pages

- Buyer authenticated: `buyer.stock-alerts.index`

## New Permissions

- Added `ProductStockAlertPolicy` for buyer/admin visibility and buyer-owned cancellation.

## Deployment Notes

- Run migrations.

## Breaking Changes

- None.

## Migration Steps

1. Deploy code.
2. Run `php artisan migrate`.
3. Optionally run `php artisan db:seed --class=DatabaseSeeder` for demo data.
4. Run `npm run build`.
5. Verify out-of-stock product subscription and buyer alert list behavior.

## Known Issues

- Guest email alerts are intentionally not supported.
- Notifications are database-only for buyers in this release.
- Seller-side analytics for stock-alert demand is not implemented.

## Rollback Notes

- Revert the feature commit and roll back the migration to remove stock alerts.
- Existing alert records are removed when the migration is rolled back.
