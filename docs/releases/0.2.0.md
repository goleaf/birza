# Release 0.2.0 - Product Comparison System

## Metadata

- Version: `0.2.0`
- Release date: 2026-06-07
- Release type: minor pre-release feature
- Related commits: `feat: add product comparison system`
- Related issues: none documented
- Git tag: not created by this implementation

## Summary

This release adds a product comparison system so guest users and authenticated buyers can compare several public products before deciding what to buy.

## Main Changes

- Added a session-backed comparison list with a four-product maximum.
- Added compare buttons to buyer product cards and product detail pages.
- Added a responsive comparison page with empty, loading, remove, clear, and back-to-catalog states.
- Moved buyer product index and detail routes outside the authenticated buyer group so guests can browse and compare products.

## Added

- `AddProductToCompareAction`, `RemoveProductFromCompareAction`, `ClearProductCompareAction`, and `GetComparedProductsAction`.
- `ProductComparison` support class for session storage, public product resolution, duplicate prevention, limit enforcement, and unavailable-product pruning.
- Buyer comparison Livewire page at `buyer.compare.index`.
- English and Lithuanian translation keys for comparison actions, fields, states, and messages.
- Standalone `ProductComparisonSeeder` with comparison-friendly demo products.
- PHPUnit coverage for guest and authenticated comparison behavior.

## Changed

- Buyer product index and product detail pages are publicly reachable so guest users can add products to comparison.
- Buyer catalog product cards use responsive grid columns while keeping existing filters, search, and pagination behavior.

## Fixed

- None.

## Removed

- None.

## Security

- Comparison only resolves active, non-deleted products from active verified sellers.
- Admin-only data, seller emails, audit fields, balances, and internal moderation data are not exposed on the comparison page.

## Deprecated

- None.

## Database Changes

- No migration was added.
- No comparison table was added; comparison state is stored in the session.
- Added a standalone seeder only: `database/seeders/ProductComparisonSeeder.php`.

## Configuration Changes

- No new `.env` keys.
- No config file changes.

## New Routes Or Pages

- Buyer/public: `buyer.compare.index`
- Buyer/public: `buyer.products.index` is now public.
- Buyer/public: `buyer.products.show` is now public.

## New Permissions

- No new policy or role was added.
- Public comparison safety is enforced by the comparison action/query layer.

## Deployment Notes

- Run migrations as usual; no new migration is required for this feature.
- Run `php artisan db:seed --class=ProductComparisonSeeder` only if comparison demo products are wanted.
- Run `npm run build` after deploying frontend changes.

## Breaking Changes

- Buyer product index and product detail pages are now guest-accessible instead of buyer-auth-only.

## Migration Steps

1. Deploy code.
2. Run the normal migration command for the environment.
3. Optionally run `php artisan db:seed --class=ProductComparisonSeeder` for demo comparison products.
4. Run the frontend build.
5. Verify guest and authenticated buyer comparison flows.

## Known Issues

- Comparison is session-scoped and does not sync across devices or browsers.
- Out-of-stock products can still appear in comparison, but they are clearly marked as out of stock.
- If a compared product becomes inactive, deleted, or seller-unavailable, it is pruned from the comparison list the next time the list is resolved.

## Rollback Notes

- Revert the feature commit to remove the comparison system.
- No database rollback is required.
- Clear affected user sessions if stale comparison IDs should be removed immediately.
